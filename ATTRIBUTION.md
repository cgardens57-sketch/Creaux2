# Creaux2 Attribution

Creaux2 is a source-independent desktop music player whose application shell
and interaction system are original, while its provider and playback engine is
derived from [Nuclear](https://github.com/nukeop/nuclear).

## Creaux2 interface work

The Creaux2 fork replaces Nuclear's rendered frontend with an original
application shell, information architecture, visual system, motion language,
interaction audio, navigation, empty states, source management, application
iconography, and Windows packaging identity. Nuclear's provider registry,
plugin runtime, metadata search, dashboard, discovery, stream resolution,
playback, queue, playlist, history, favorites, and persistence architecture
remains the functional engine.

The main interface was informed by high-level design principles observed in
Final Fantasy XIII, Granblue Fantasy, and Zektbach-related work. No production
UI assets from those properties are included. The main Creaux2 interface
geometry and effects are code-native and original to this fork.

The optional Cirno and Remilia easter egg uses user-supplied character images
and audio stored under `packages/player/src/creaux/assets`. Those files are not
part of Nuclear and are not covered by claims of original Creaux2 interface
authorship.
